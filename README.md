Nội dung bài tập 

1. Encapsulation – Tính đóng gói

Ví dụ quản lý tồn kho sản phẩm. Sử dụng private để bảo vệ dữ liệu và phương thức Sell() để kiểm soát số lượng bán.

2. Inheritance – Tính kế thừa

Ví dụ class Phone và Clothing kế thừa từ class Product, giúp tái sử dụng thuộc tính và phương thức chung.

3. Polymorphism – Tính đa hình

Ví dụ thanh toán bằng tiền mặt và chuyển khoản. Sử dụng virtual và override để thực hiện phương thức Pay() theo các cách khác nhau.

4. Abstraction – Tính trừu tượng

Ví dụ tính giảm giá cho khách hàng thường và VIP. Sử dụng abstract class và phương thức abstract.

5. Open/Closed Principle – Nguyên lý đóng/mở

Ví dụ tính phí đóng gói sản phẩm. Có thể bổ sung loại đóng gói mới mà không cần sửa logic xử lý cũ.
